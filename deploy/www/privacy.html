Smartboss

นโยบายความเป็นส่วนตัว

หน้านี้อธิบายว่า Smartboss เก็บข้อมูลอะไรของคุณ เก็บไปทำไม เก็บไว้นานแค่ไหน และคุณขอให้ทำอะไรกับข้อมูลนั้นได้บ้าง

ปรับปรุงล่าสุด: 9 กันยายน 2569

⚠ ก่อนเผยแพร่จริง ต้องเติม 3 อย่าง — ชื่อนิติบุคคลเต็ม, ที่อยู่, และอีเมลติดต่อเรื่องข้อมูลส่วนบุคคล (ค้นคำว่า [[ ในไฟล์นี้) · และควรให้คนที่รู้ PDPA อ่านทวนหนึ่งรอบ เพราะหน้านี้เป็นเอกสารที่มีผลผูกพัน ไม่ใช่แค่ข้อความประกอบ · ลบกล่องนี้ทิ้งเมื่อเติมครบแล้ว

1. ใครเป็นคนดูแลข้อมูลของคุณ

Smartboss เป็นระบบที่ บริษัทนายจ้างของคุณ ซื้อมาใช้บริหารงานบุคคล การแบ่งหน้าที่จึงเป็นแบบนี้:

  • บริษัทนายจ้างของคุณ = ผู้ควบคุมข้อมูลส่วนบุคคล — เป็นผู้ตัดสินว่า จะเก็บอะไร ใช้ทำอะไร และเปิดให้ใครในบริษัทเห็นได้บ้าง
  • [[ชื่อนิติบุคคลเต็มของผู้ให้บริการ Smartboss]] = ผู้ประมวลผลข้อมูลส่วนบุคคล — ทำหน้าที่เก็บรักษาและประมวลผลตามคำสั่งของบริษัทนายจ้างเท่านั้น เราไม่นำข้อมูลของคุณไปขาย ไม่นำไปใช้โฆษณา และไม่ใช้ข้ามบริษัท

ถ้าคุณอยากใช้สิทธิ์เกี่ยวกับข้อมูลของตัวเอง ให้เริ่มที่ฝ่ายบุคคลของบริษัทคุณก่อน เพราะเป็นผู้ควบคุมข้อมูล — เราดำเนินการให้ตามที่บริษัทแจ้งมา

2. ข้อมูลที่เก็บ และเก็บไปทำไม

ข้อมูลเก็บเมื่อไรเก็บไปทำไม
ชื่อ อีเมล ตำแหน่ง แผนก เมื่อบริษัทเพิ่มคุณเข้าระบบ ระบุตัวตน กำหนดสิทธิ์การเข้าถึง
LINE user ID และชื่อที่แสดงใน LINE เมื่อคุณผูกบัญชี LINE กับ Smartboss ด้วยตัวเอง ให้คุณเข้าใช้งานผ่าน LINE ได้โดยไม่ต้องจำรหัสผ่าน และส่งแจ้งเตือนถึงคุณ
ตำแหน่งที่ตั้ง (พิกัด GPS) และค่าความแม่นยำ เฉพาะตอนที่คุณกดลงเวลาเข้า-ออกงานเท่านั้น ตรวจว่าคุณอยู่ในบริเวณสถานที่ทำงานตามที่บริษัทกำหนด
ภาพถ่ายขณะลงเวลา เฉพาะตอนลงเวลา และเฉพาะเมื่อบริษัทคุณตั้งนโยบายให้ต้องถ่าย ยืนยันว่าเป็นตัวคุณจริง ไม่ใช่ให้คนอื่นลงเวลาแทน
เวลาเข้า-ออกงาน การลา การทำงานล่วงเวลา ตลอดการจ้างงาน คำนวณเวลาทำงานและค่าจ้าง
ค่าจ้างและข้อมูลการจ่ายเงินเดือน ตามรอบจ่าย ออกสลิปและนำส่งหน่วยงานรัฐตามกฎหมาย
เลขประจำตัวประชาชน เลขผู้เสียภาษี เมื่อบริษัทบันทึกเข้าระบบ ใช้ตามที่กฎหมายภาษีและประกันสังคมกำหนด — เก็บแบบเข้ารหัส
ข้อมูลลายนิ้วมือ (เฉพาะบริษัทที่ใช้เครื่องสแกน) เมื่อลงทะเบียนนิ้วกับเครื่อง ลงเวลาด้วยการแตะนิ้ว — ระบบเก็บเพียงค่าตรวจสอบ (hash) เท่านั้น ไม่เก็บภาพลายนิ้วมือและไม่เก็บแม่แบบลายนิ้วมือ จึงย้อนกลับไปเป็น ลายนิ้วมือของคุณไม่ได้
บันทึกการใช้งาน (ใครทำอะไร เมื่อไร) ตลอดการใช้งาน ตรวจสอบย้อนหลังเมื่อมีข้อโต้แย้ง และความปลอดภัยของระบบ

เรื่องตำแหน่งที่ตั้ง — ขอให้ชัดเจน

Smartboss ไม่ติดตามตำแหน่งของคุณตลอดเวลา และไม่ทำงานอยู่เบื้องหลัง ระบบขอพิกัด เฉพาะวินาทีที่คุณกดปุ่มลงเวลาเท่านั้น ถ้าคุณไม่กด ก็ไม่มีการขอพิกัด และคุณปฏิเสธไม่ให้สิทธิ์กับเบราว์เซอร์ได้เสมอ (แต่บริษัทอาจกำหนดว่าถ้าไม่มีพิกัด จะลงเวลาด้วยวิธีนี้ไม่ได้)

3. เก็บไว้นานแค่ไหน

  • ภาพถ่ายขณะลงเวลา — เก็บตามระยะที่บริษัทคุณตั้งไว้ (ค่าเริ่มต้นของระบบคือ 90 วัน) แล้วลบอัตโนมัติ
  • ข้อมูลเวลาทำงานและค่าจ้าง — เก็บตามระยะที่กฎหมายแรงงานและกฎหมายภาษี กำหนดให้นายจ้างต้องเก็บ
  • LINE user ID — เก็บจนกว่าคุณจะยกเลิกการผูกบัญชี หรือพ้นสภาพพนักงาน
  • เมื่อบริษัทคุณเลิกใช้บริการ ข้อมูลจะถูกลบหรือส่งคืนตามที่ตกลงกันในสัญญาบริการ

4. เราเปิดเผยข้อมูลให้ใครบ้าง

  • คนในบริษัทคุณ ที่ได้รับสิทธิ์ เช่น หัวหน้างาน ฝ่ายบุคคล ตามที่บริษัทกำหนด
  • หน่วยงานรัฐ เท่าที่กฎหมายกำหนด เช่น กรมสรรพากร สำนักงานประกันสังคม
  • ผู้ให้บริการโครงสร้างพื้นฐาน ที่จำเป็นต่อการให้บริการ เช่น ผู้ให้บริการเซิร์ฟเวอร์
  • LINE เฉพาะเท่าที่จำเป็นต่อการส่งข้อความแจ้งเตือนถึงคุณ

เราไม่ขายข้อมูลของคุณ และไม่ใช้ทำโฆษณา

5. ความปลอดภัย

  • รับส่งข้อมูลผ่านการเชื่อมต่อที่เข้ารหัส (HTTPS) ทั้งหมด
  • เลขประจำตัวประชาชนและข้อมูลบัญชีธนาคารถูกเข้ารหัสก่อนบันทึก
  • ข้อมูลของแต่ละบริษัทถูกแยกจากกันในระดับฐานข้อมูล
  • รูปหลักฐานการลงเวลาเปิดดูได้เฉพาะผู้มีสิทธิ์ และทุกครั้งที่เปิดดูจะถูกบันทึกไว้

6. สิทธิ์ของคุณ

ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) คุณมีสิทธิ์:

  • ขอดูข้อมูลส่วนบุคคลของคุณที่ระบบเก็บไว้ และขอสำเนา
  • ขอให้แก้ไขข้อมูลที่ไม่ถูกต้อง
  • ขอให้ลบหรือระงับการใช้ข้อมูล ในกรณีที่กฎหมายให้ทำได้
  • คัดค้านการเก็บหรือใช้ข้อมูลบางประเภท
  • ขอถอนความยินยอมที่เคยให้ไว้ เช่น ยกเลิกการผูกบัญชี LINE
  • ร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล

วิธีใช้สิทธิ์: ติดต่อฝ่ายบุคคลของบริษัทคุณเป็นลำดับแรก หรือติดต่อเราตามช่องทางในข้อ 8

7. การผูกบัญชี LINE

การผูกบัญชี LINE เป็นทางเลือก ไม่ใช่ข้อบังคับ เมื่อคุณผูกบัญชี เราจะได้รับ รหัสผู้ใช้ LINE ชื่อที่แสดง และรูปโปรไฟล์ ของคุณ เราไม่เห็นข้อความส่วนตัว รายชื่อเพื่อน หรือกลุ่มใด ๆ ของคุณ

คุณยกเลิกได้ตลอดเวลาโดยบล็อกหรือลบบัญชีทางการ Smartboss ออกจากรายชื่อเพื่อน หรือแจ้งฝ่ายบุคคลให้ยกเลิกการผูกบัญชีให้
